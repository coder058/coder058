Full-stack developer · AI-assisted delivery · Python, TypeScript and SQL

I turn product goals into full-stack software, using AI coding agents across implementation, testing, debugging and refactoring. My independent work connects usable interfaces, APIs and data workflows with reproducible checks.

## How I work

Define the problem and scope, break it into testable changes, iterate with AI agents, and check the result against source data, regression tests and browser behaviour. AI assistance is part of development; it does not mean every application contains an AI model.
